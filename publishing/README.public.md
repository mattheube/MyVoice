# MyVoice — 2.7.0 Beta 11

Installez MyVoiceSetup.exe, ou extrayez entièrement le ZIP portable avant de lancer MyVoice.exe. Windows 10/11 x64 est requis. Le runtime .NET est inclus. Les environnements et modèles IA sont préparés automatiquement en arrière-plan, avec une commande de réparation dans les paramètres.

Vos réglages et bibliothèques restent dans %APPDATA%/MyVoice. Les moteurs locaux restent dans %LOCALAPPDATA%/MyVoice. La mise à jour et la désinstallation conservent ces données.

Au démarrage, MyVoice recherche la dernière release complète du canal choisi sur GitHub, vérifie son empreinte et l’installe avant d’ouvrir le studio. En cas d’échec, la version précédente peut être restaurée. Stable et Beta restent séparés.

Community est connecté. La connexion par Discord est disponible ; l’affichage de MyVoice dans Discord est une option distincte, désactivée par défaut. Les sons et références restent locaux tant que vous ne choisissez pas de les publier. Le micro virtuel utilise toujours VB-CABLE : le pilote propriétaire My Voice n’est pas encore distribuable.

Cette Beta apporte notamment le nettoyage RNNoise du micro, dix thèmes, le flou natif sous Windows 11 compatible, les raccourcis centralisés, les bannières, l’édition des publications, et quatre packs de sons originaux. Le matériel influence fortement la vitesse et la qualité des voix IA.
