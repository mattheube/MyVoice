MyVoice 2.7.0-beta.9 — targeted update audit, 19 October 2026

IMPLEMENTATION
Draft close: Save / Discard / Cancel; unchanged closes directly. Save updates the same draft. Discard only removes the current unpublished package. Cover changes update the package and hashes. Original creations and archived drafts remain intact.
Language: first-run and Settings French/English selection; expanded labels, tooltips and runtime messages. Stable model/device choices retain selection. User content, device names and engine diagnostics remain original. Portuguese is a speech language, not an application UI language.
Glass: optional static theme-coloured reflections and layered surfaces/borders, unchanged layout. OFF restores the original palette. Tray/background, reduced effects, disabled Windows animations, high contrast and unsupported rendering tiers use the fallback. No continuous backdrop capture.
Studio: Live Microphone, Audio Conversion, Text to Voice. Import or record up to 120 seconds; export, headphones preview or play through the existing My Voice mixer channel (routing/volume/mute retained). Cancellation supported. Text uses the selected prepared reference, a separate optional runtime, and bounded phrases up to 1000 characters total.
Formats: WAV/FLAC/MP3/OGG/OPUS/M4A/AAC import; WAV PCM24, FLAC, MP3 320k, OGG q8, OPUS 192k export at 44.1/48kHz. Extension/header validation followed by actual decoding. Originals preserved. Mixed imports report rejected files. Image drops use the crop editor.
Reference review: pending samples do not activate until explicit Update Voice confirmation. Approved banks persist across restart and revisions; publication excludes pending samples and private paths. Peak-aware normalization avoids introducing clipped transients. Analysis detects short audio, silence/low level and clipping; music, multiple speakers and reverberation are not reliably classified, as explained in tips.
